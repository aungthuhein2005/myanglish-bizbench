## What changed between the versions

- **Gold intents: no change.** The review kept all 148 intent labels. So every intent score change comes from the **v0.2 prompt** (new rules, e.g. greeting can combine with other intents) and from run-to-run variation, not from relabelling.
- **Gold entities: 15 samples changed.** 7 `issue` values mapped to the fixed issue list, 1 location split into one value per place, and 7 entities added by the reviewer (payment methods, dates, sizes).
- **Message texts: no change.** The reviewer's spelling edits to 10 messages were not used, so both versions score the same inputs.

## Findings

1. **Entity F1 rose for every model** (+8.7 to +14.7 points, except DeepSeek at +0.5). Two things changed together: the gold labels (fixed issue list, one value per place) and the prompt's entity rules, so models now produce values in the same format as the gold. This removes most of the strict-matching failures found in the v0.1 failure analysis; the two causes are not separated here.
2. **Intent scores fell slightly for 5 of 6 models** (Macro F1 −0.4 to −3.3, exact match −3 to −9 for all six). Gold intents did not change, so the v0.2 prompt (plus run-to-run noise) is the cause. The v0.2 prompt's rules match the guidelines, but some v0.1 gold intents may not yet follow those rules (the review kept them all); a per-sample look at the newly failed cases is the next check. Gemma's Macro F1 rose (+2.8).
3. **Ranking is stable.** Claude, GPT, Gemini and Qwen are still the top group on intents; DeepSeek and Gemma trail. On entities, Gemini now leads (86.5).
4. **Cost rose about 20–45%** because the v0.2 prompt is longer.

## Caveats

- One run per model; differences of 1–2 points are within run-to-run noise on 100 samples.
- The v0.2 rules were written after seeing v0.1 results (disclosed in the guidelines). The gold intents were not changed, so the intent comparison is clean; the entity gains partly reflect rules chosen to fix known strict-matching problems.
- Qwen's run hit OpenRouter rate limits; 60 samples were re-run with one worker, so the run is complete.
