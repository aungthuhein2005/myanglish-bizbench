### Entity error types

**Near-miss value**: right key, value overlaps but is not identical (e.g. `yankin` vs `yankin yangon`) — mostly an evaluation strictness issue. **Wrong key**: right value under another key. **Missed**: gold entity with no match. **Extra**: predicted entity with no match (a hallucination *or* an entity the gold labels left out).
